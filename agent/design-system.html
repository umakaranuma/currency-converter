The screen

One task, one view. A gradient header carries identity and the live-rate pulse; a card floats over its edge so the amount you're entering is always the brightest thing on screen. Results are cards, not table rows — each pairs the converted figure with the exact rate behind it.

Color

Indigo leads because it reads as calm and dependable next to money. Emerald is reserved for “you receive” and healthy status — it is not a second accent. Neutrals carry a faint indigo bias so greys feel chosen, not default. Every role is defined for both themes; components only ever read tokens.

Contrast

Body and label text clears WCAG AA on every surface in both themes; the gradient uses white text and deepens its stops in dark mode to stay above 4.5:1.

Touch targets

Every tappable element is at least 44×44 px including the banner’s retry and dismiss controls.

Motion

Only two animations — the live-rate pulse and the skeleton shimmer. Both stop under prefers-reduced-motion.

Focus

Keyboard focus shows a 2 px primary outline offset from the element; never removed, only restyled.
